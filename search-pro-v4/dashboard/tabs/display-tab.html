Order of Results

Drag the kinds of result into the order visitors should see them in the search.

Order of the Groups

Results are listed in groups, one for each kind. Drag a row by its handle to move it, or use the arrow buttons. The group at the top is listed first. Names are the ones set in Element Types. A kind that is switched off in Content never shows.
