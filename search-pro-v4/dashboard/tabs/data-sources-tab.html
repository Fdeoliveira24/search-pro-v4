Data Sources Settings

Use a Google Sheet or a CSV file to change how items look in the search results; the tour itself is never changed

Source

Choose where the extra information comes from. Only one source is active at a time.

Any Google Sheets link works: sharing, edit or published. Share the sheet as "Anyone with the link → Viewer".

A path inside the search-pro-v4 folder, or a full web address. The tour must be opened through a web server, not straight from disk.

Sheet Columns

One row describes one item of the tour. Only what you fill in changes; empty cells keep the tour's own value.

Column What to put in it
id Which tour item this row is about: its Title, Tag, Subtitle or internal id, written exactly (capital letters do not matter).
tag Optional second chance: used only if id finds nothing.
name The title shown in the search result.
description The text under the title. It shows while Display > Show Subtitles in Results is on.
imageUrl The picture shown in the result (web address or a path in the assets folder). It shows only while Display > Show Pictures in Results is on, and for a kind whose Picture switch in Display > Element Types is on.
tags The tags shown in the result, separated by commas. They show while Display > Show Tags in Results is on.
elementType Panorama, Video360, FlatVideo, Album, Map, Hotspot, Polygon, Video, Webframe, Image, ProjectedImage, Text, 3DModel, 3DHotspot, 3DModelObject or Audio. Helps pick the right item when names repeat.
parentId The panorama or 3D model the item lives in (same rule as id). Use it when a title repeats, and for rows whose item is not in the tour: clicking them jumps to this panorama.
  • Rows that cannot be matched to anything in the tour are not shown in the search.
  • A title that exists in several panoramas (for example a hotspot) needs a parentId to choose one; otherwise every match is changed.
  • The first row holds the column titles. Commas, semicolons or tabs can separate columns.
  • A sheet changes how results look after Content and Filtering have decided what is searched: those settings use the names and tags of the tour, not the ones from the sheet.
