How to add the search to a tour, how your settings reach visitors, what each tab does and what to check when something does not work

Saving and Sharing Your Settings

Find out who sees what you change, and which step puts it in front of your visitors.

Visitors only see your settings after you download the settings file and upload it to your tour.
What You Do What Happens Who Sees It
Change a setting A tour that is open in this browser follows at once. Only you, in this browser
Apply Settings Keeps your settings in this browser. A tour you open here later uses them, and the Control Panel offers to bring them back the next time you open it. Only you, in this browser
Download Saves your settings as the file search-pro-config.js. Nobody yet
Upload the file to your tour Puts the file in search-pro-v4/config/ on your server (see below). Every visitor of the tour
Load Reads a settings file you saved earlier back into the Control Panel, so you can keep editing it. Use a file you downloaded from this Control Panel. A tour that is open in this browser follows. Only you, until you download and upload again
Reset Puts every setting back to its default, also in a tour that is open in this browser, and removes the copy kept in this browser. The file on your server stays as it is. Only you, in this browser

Add the Search to Your Tour

Do this once for each tour. The search then appears when a visitor presses your search button.

  1. Copy the folder Put the search-pro-v4 folder in your tour folder, at the same level as the index.html file: both sit side by side in the same folder.
  2. Open index.html in a code editor and add two lines Find the line <div id="viewer" class="fill-viewport"></div> and paste the two lines right after it, before </body>. The search engine goes first and the settings file second: this is the order we tested. Add the second line when you have downloaded your settings file. Publishing again from 3DVista writes a new index.html, so add the two lines again after each publish. 
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  3. Give your search button its action In 3DVista, open the Skin tab and add an Icon Button. In its Actions choose Execute JavaScript, paste this code and click Done. The button then opens the search, and closes it when it is open. 
    try {
    var searchContainer = document.getElementById('searchContainer');
    if (searchContainer) {
        if (!window.searchListInitiinitialized) {
            window.tourSearchFunctions.initializeSearch(this);
        }
        window.tourSearchFunctions.toggleSearch(searchContainer.style.display !== 'block');
    }
} catch (error) {
    console.error('Button action error - Check if initialization is complete:', error);
}
  4. Publish and try it Publish your tour from 3DVista, open it and press the button. The first press prepares the search, which takes a moment in a large tour.

Upload Your Settings File

Do this every time you want visitors to see new settings.

  1. Download the file Press Download in the top bar. Your browser saves search-pro-config.js.
  2. Upload it to your tour With your FTP program or the file manager of your hosting, put it in search-pro-v4/config/ and replace the old one. The server must be allowed to read it (permission 644 is usual). If your Data Source is a CSV file, upload that file too, to the path you wrote in Data Sources.
  3. Reload the tour without the cache Press Cmd+Shift+R on a Mac or Ctrl+F5 on Windows. A browser keeps the old files for a while, and then shows the old settings or an old version of the search.

Update to a New Version

Your settings file stays. Only the plugin files change.

  1. Keep a copy of your settings file Copy search-pro-v4/config/search-pro-config.js to your computer.
  2. Upload the new files over the old ones Upload the files of the new search-pro-v4 folder and replace the ones that are there. Do not delete the config folder: your settings file lives in it.
  3. Reload, then download your file again Reload the tour without the cache. Then open the Control Panel, press Load with your settings file, look through the tabs and press Download, so the file carries the settings the new version added. Upload that file to config.

What the Search Finds

What a visitor can find by typing, and what is out of reach.

What Found? Good to Know
Names of panoramas, hotspots, 3D models, containers and other elements Yes The name you gave it in 3DVista. A hotspot's tooltip is its name, so a tooltip is found the same way.
Subtitles and tags Yes Both are searched. Display decides whether a result shows them.
Names, descriptions and tags from a Data Source Yes The tour's own name still finds the item too.
PDF documents that a hotspot opens Yes, by name The result is named after the hotspot, or after the file when the hotspot has only a default name. Turn on PDF in Content.
Words written inside a picture, such as a hotspot called Text No The words are part of the picture. Give the hotspot a name or tags in 3DVista, or describe it in a Data Source.
Text boxes and labels of the skin No They belong to the skin of your tour, not to a panorama.
The words inside a PDF No Only the name of the PDF is searched.

Find and Check Your Settings

Four helpers that save you time while you work.

Helper Where What It Does
Search Settings The top bar, or Ctrl or Cmd + K Type a word, such as phone or delay, and jump to the setting. It also finds words on this page.
Live Preview The Preview button, or Alt + Shift + P Shows the real search with your settings on a sample tour, not your own. Choose Desktop or Phone, and Results, Nothing Found or Empty Field. It needs a window at least 640 px wide.
Scan the Open Tour Advanced Lists what the search can see in the tour that is open in this browser.
Test This Source Data Sources Reads your Google Sheet or CSV file and says which rows found their place in the tour, and why the others did not.

Shortcuts

Keys for you in the Control Panel and for your visitors in the tour.

Keys What They Do Where
Ctrl or Cmd + S Applies your settings. Control Panel
Alt + Shift + D Downloads the settings file. Control Panel
Alt + Shift + L Loads a settings file. Control Panel
Ctrl or Cmd + K Opens the search of the Control Panel: type a word to find a setting and jump to it. This is not the search your visitors use in the tour. Control Panel
Alt + Shift + P Opens or closes the Live Preview. Control Panel
Escape Closes the search of the Control Panel, the Live Preview or an open message window. Control Panel
Ctrl or Cmd + K Opens the search for your visitors (not the search of the Control Panel). When the Search Bar is already on screen, it puts the cursor in the field. You can turn this off in General. Tour
Escape Clears the search field and hides the Search Results. By default the Search Bar goes too. With Also Hide the Search Bar With the Escape Key off, the Search Bar stays and the tour keeps Escape while the field is empty. You can turn this off in General. Tour

Words Used in the Control Panel

What the words on the pages mean.

Word What It Means
Result One line in the list a visitor sees: a panorama, a hotspot, a 3D model, a container and so on.
Group The results of one kind listed together under one heading, for example Hotspot. The order of the groups is set in Display.
Kind What a result is: Panorama, 360 Video, Hotspot, 3D Model and so on. Content switches kinds on and off.
Element Anything you add to a panorama in 3DVista: a hotspot, polygon, image, text, video or web frame.
Container A 3DVista element that holds other elements, such as a menu, a gallery or a floor plan.
Playlist The list of panoramas a tour plays through. With Include into PlayList switched off, 3DVista gives that media a playlist of its own.
Hidden Window A window or container your tour keeps closed until a button opens it, such as the floor plan or a video. Choosing a result can open it (General).
Tag and Subtitle Words you give an element in 3DVista. The search finds them and a result can show them.
Data Source A Google Sheet or a CSV file with names, descriptions, pictures and tags for your results. It changes how results look and what visitors can find; the tour itself is never changed.
Settings File The file search-pro-config.js that Download saves. Visitors see your settings when it is on your server.
Live A change that reaches a tour open in this browser at once, before you press Apply Settings.

When Something Does Not Work

Find your problem and check these things in this order.

Problem What to Check
My settings do not show in the tour Apply Settings only changes this browser. Download the file, upload it to search-pro-v4/config/ and reload the tour without the cache. In index.html check that the search engine line comes first and the settings line second.
The search button does nothing Check that the button has the JavaScript action from this page and that search-pro-v4/search-v4.js loads (look for a red message in the browser console).
A result I expect is missing Check which kinds are switched on in Content and what Filtering hides. Scan the Open Tour in Advanced shows what the search can see in your tour.
My Google Sheet or CSV file changes nothing Open Data Sources and press Test this source: it names the cause, such as a private sheet, a wrong link or a file that is not found. Then download your settings file again, upload it and reload the tour without the cache. If the table cannot be read, visitors still get the search with the names of the tour.
I changed the sheet but the tour shows the old text If Keep a Copy is on in Data Sources, a visitor's browser keeps the sheet for the minutes set there. A CSV file is never copied, but the browser may keep the old file: reload without the cache.
A row of my table is not in the results A row that matches nothing in the tour and has no parentId is not shown. Test this source lists every row with the reason.
A PDF document is missing Turn on PDF in Content. The search lists the PDF that a hotspot opens, by the name of the hotspot or the file. It does not read the words inside the PDF.
Choosing a result does not show the floor plan, photo album or video Your tour keeps those in a window or container that is hidden. Turn on Open Hidden Windows and Containers in General: the result then shows that window first.
A video or a window is missing from the search A media that 3DVista shows in a hidden window without a width and height is left out, because it would open as a tiny box. Give that window a size in 3DVista, or use the hotspot or button that opens it. Scan the Open Tour in Advanced says how many are left out.
3D objects named Object are missing 3DVista calls the parts of a 3D file Object when nobody named them, and the search leaves them out. Turn on Objects Named Just Object in Content under Unnamed Items to find them.
The results come in the wrong order Choose the order of the groups in Order of Results in Display. Inside a group the results follow the order of your tour.
The animations do not play Turn on Enable Animations in the Animations tab. A visitor whose device asks for less motion sees only a short fade. After an update, reload the tour without the cache: the browser may keep an old script.
My changes do not reach the open tour Open the Control Panel and the tour in the same browser and at the same address. If the Control Panel is on another address, add it in Advanced under Control Panel Connection. The same goes for a tour that is shown inside another web page: that page is only listened to when its address is listed there.
My settings are gone after closing the Control Panel When you open it again it asks whether to bring them back, and it opens on the tab and card where you were. Only the downloaded file is kept for good.
