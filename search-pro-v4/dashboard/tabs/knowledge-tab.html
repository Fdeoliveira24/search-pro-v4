Saving and Sharing Your Settings

Find out who sees what you change, and which step puts it in front of your visitors.

Visitors only see your settings after you download the settings file and upload it to your tour.
What You Do What Happens Who Sees It
Change a setting A tour that is open in this browser follows at once. Only you, in this browser
Apply Settings Keeps your settings in this browser. A tour you open here later uses them, and the Control Panel offers to bring them back the next time you open it. Only you, in this browser
Download Saves your settings as the file search-pro-config.js. Nobody yet
Upload the file to your tour Puts the file in search-pro-v4/config/ on your server (see below). Every visitor of the tour
Load Reads a settings file you saved earlier back into the Control Panel, so you can keep editing it. A tour that is open in this browser follows. Only you, until you download and upload again
Reset Puts every setting back to its default, also in a tour that is open in this browser, and removes the copy kept in this browser. The file on your server stays as it is. Only you, in this browser

What Each Tab Does

Find the tab for what you want to change.

Tab Use It To Example
General Choose when the search opens and closes, where the bar sits on desktops and phones, and the words visitors read. Open the search with Ctrl + K
Appearance Change colors, fonts, borders and the look of tags and group headers. A white bar with a blue focus ring
Display Choose what each result shows, the order of the groups and the name of each kind. Panoramas first, each with a picture
Content Choose which kinds of element are searched, what happens to unnamed elements and which containers can be opened. Leave out polygons
Filtering Hide results by name, tag or panorama number. Hide everything tagged internal
Data Sources Add names, descriptions, pictures and tags from a Google Sheet or a CSV file. A sheet that describes each room
Animations Choose how the search bar and the results move. A quick fade for results
Advanced Tune how typed words are matched, see what the search finds in your open tour and connect a Control Panel hosted elsewhere. Show at most 20 results

Add the Search to Your Tour

Do this once for each tour. The search then appears when a visitor presses your search button.

  1. Copy the folder Put the search-pro-v4 folder in your tour folder, next to index.html.
  2. Add two lines to index.html Paste them just before </body>. The search engine comes first and the settings file second: in the other order the settings file cannot find the engine. Add the second line when you have downloaded your settings file. 
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  3. Give your search button its action In 3DVista, add a button and give it a JavaScript action with this code. It opens the search, and closes it when it is open. 
    try {
    var searchContainer = document.getElementById('searchContainer');
    if (searchContainer) {
        if (!window.searchListInitiinitialized) {
            window.tourSearchFunctions.initializeSearch(this);
        }
        window.tourSearchFunctions.toggleSearch(searchContainer.style.display !== 'block');
    }
} catch (error) {
    console.error('Button action error - Check if initialization is complete:', error);
}
  4. Publish and try it Open the published tour and press the button. The first press prepares the search, which takes a moment in a large tour.

Upload Your Settings File

Do this every time you want visitors to see new settings.

  1. Download the file Press Download in the top bar. Your browser saves search-pro-config.js.
  2. Upload it to your tour With your FTP program or the file manager of your hosting, put it in search-pro-v4/config/ and replace the old one. The server must be allowed to read it (permission 644 is usual).
  3. Reload the tour without the cache Press Cmd+Shift+R on a Mac or Ctrl+F5 on Windows. A browser keeps the old files for a while, and then shows the old settings or an old version of the search.

Shortcuts

Keys for you in the Control Panel and for your visitors in the tour.

Keys What They Do Where
Ctrl or Cmd + S Applies your settings. Control Panel
Alt + Shift + D Downloads the settings file. Control Panel
Alt + Shift + L Loads a settings file. Control Panel
Escape Closes an open message window. Control Panel
Ctrl or Cmd + K Opens the search. You can turn this off in General. Tour

Words Used in the Control Panel

What the words on the pages mean.

Word What It Means
Result One line in the list a visitor sees: a panorama, a hotspot, a 3D model, a container and so on.
Group The results of one kind listed together under one heading, for example Hotspot. The order of the groups is set in Display.
Kind What a result is: Panorama, 360 Video, Hotspot, 3D Model and so on. Content switches kinds on and off.
Element Anything you add to a panorama in 3DVista: a hotspot, polygon, image, text, video or web frame.
Container A 3DVista element that holds other elements, such as a menu, a gallery or a floor plan.
Playlist The list of panoramas a tour plays through. With Include into PlayList switched off, 3DVista gives that media a playlist of its own.
Hidden Window A window or container your tour keeps closed until a button opens it, such as the floor plan or a video. Choosing a result can open it (General).
Tag and Subtitle Words you give an element in 3DVista. The search finds them and a result can show them.
Settings File The file search-pro-config.js that Download saves. Visitors see your settings when it is on your server.
Live A change that reaches a tour open in this browser at once, before you press Apply Settings.

When Something Does Not Work

Find your problem and check these things in this order.

Problem What to Check
My settings do not show in the tour Apply Settings only changes this browser. Download the file, upload it to search-pro-v4/config/ and reload the tour without the cache. In index.html the search engine line must come before the settings line.
The search button does nothing Check that the button has the JavaScript action from this page and that search-pro-v4/search-v4.js loads (look for a red message in the browser console).
A result I expect is missing Check which kinds are switched on in Content and what Filtering hides. Scan the Open Tour in Advanced shows what the search can see in your tour.
Choosing a result does not show the floor plan, photo album or video Your tour keeps those in a window or container that is hidden. Turn on Open Hidden Windows and Containers in General: the result then shows that window first.
A video or a window is missing from the search A media that 3DVista shows in a hidden window without a width and height is left out, because it would open as a tiny box. Give that window a size in 3DVista, or use the hotspot or button that opens it. Scan the Open Tour in Advanced says how many are left out.
3D objects named Object are missing 3DVista calls the parts of a 3D file Object when nobody named them, and the search leaves them out. Turn on Objects Named Just Object in Content under Unnamed Items to find them.
The results come in the wrong order Choose the order of the groups in Order of Results in Display. Inside a group the results follow the order of your tour.
The animations do not play Turn on Enable Animations in the Animations tab. A visitor whose device asks for less motion sees only a short fade. After an update, reload the tour without the cache: the browser may keep an old script.
My changes do not reach the open tour Open the Control Panel and the tour in the same browser and at the same address. If the Control Panel is on another address, add it in Advanced under Control Panel Connection.
My settings are gone after closing the Control Panel When you open it again it asks whether to bring them back. Only the downloaded file is kept for good.
