What Is Searched

Choose which kinds of elements visitors can find. An element of a kind that is off is not in the search at all.

Type What It Is In Search
Panorama A 360° scene of a place in the tour. Visitors jump to it.
360 Video A video that surrounds the visitor, listed with the panoramas.
Flat Video A regular rectangular video that is one of the scenes of the tour.
Hotspot A clickable marker placed on a panorama.
Polygon A clickable area drawn on a panorama.
Video A video placed on a panorama (a video overlay).
Webframe A web page shown on a panorama.
Text A text placed on a panorama.
Projected Image A picture projected onto the surface of a panorama.
Other Elements Anything on a panorama that is none of the kinds above.
3D Model A 3D model that visitors can look at from all sides.
3D Hotspot A clickable marker placed on a 3D model.
3D Model Object A part of a 3D model that has its own name.
Audio A sound or music file of the tour. Clicking its result plays it, or pauses it while it plays. Off until you turn it on.
PDF A PDF document that a hotspot opens, named after the hotspot or the file. The hotspot keeps its own result. Off until you turn it on.
Photo Album A gallery of photos. Off until you turn it on.
Map A floor plan or map of the tour. Off until you turn it on.
Image A picture placed on a panorama.

Containers are set up in their own section below. How each kind is named, pictured and shown is set in Display > Element Types; hiding single elements by name or tag is set in Filtering.

Every kind is off, so visitors will not find anything. Turn on at least one kind.

Unnamed Items

Choose which elements without a title are in the search, and how short a name may be.

Elements Without a Title

An element is unnamed when it has no title in 3DVista. What an unnamed element is called in the results is set in Display > Unnamed Items: its subtitle, the panorama it is in, its tags or the text "[Unnamed Item]".

Toggle to include elements that have no title but have a subtitle
Toggle to include elements that have no title and no subtitle but have tags
Toggle to include elements that have no title, no subtitle and no tags

3D Objects With a Default Name

3DVista names the parts of a 3D file "Object" when the 3D artist did not name them, and a model can hold dozens of them. Visitors cannot tell them apart, so they are left out of the search.

Toggle to include 3D objects that carry the default name Object

Containers

Let visitors open and close a container of your tour from the search.

A container is an element of 3DVista that holds other elements, such as a menu, a gallery or a floor plan. You drop it on the tour canvas in 3DVista and give it a name. A container is not found by itself: add its name below, or pick it from the open tour. When a visitor picks it in the search, it opens, or closes if it was already open.
Toggle to include the containers listed below in the search
Container Names
