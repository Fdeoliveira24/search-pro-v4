# Search Pro V4 - Production Build Status

## Current Version: 4.5.0 (Maintenance and Control Panel Release)

**Last Updated:** October 7, 2026

## Version History

### V4.5.0 (October 7, 2026) - Maintenance and Control Panel Release
The public API and the Button contract used by the tour are unchanged.
- **Cleanup:** 15 unused functions, an unused CSV shim and cache-buster leftovers removed from `search-v4.js` (about 950 lines); CSS and Control Panel CSS cleaned (no visual change)
- **Security:** postMessage origin check enforced, prototype-pollution guard in `updateConfig`, HTML escaping and icon sanitising, integrity hashes on the CDN fallbacks
- **Fixes:** debug mode crash, 3D model + Google Sheets crash, Fuse.js loading late, repeat Button presses, first ArrowDown, searchBar-only live updates, CSV quoted fields, data sources following config changes, progressive-loading refresh, quick reopen wiping typed text, highlighting inside HTML entities, search icon vanishing after the search is closed
- **3D:** 3D hotspot results centre the camera on the hotspot; 3D object results centre and frame the camera on the object (and still fire their click)
- **Live settings:** the tour applies Control Panel changes instantly (`storage` event; the 2 s check stays as a backup)
- **Control Panel:** previous session can be restored after a reload; `Ctrl/Cmd+R`, `Ctrl/Cmd+D` and `Ctrl/Cmd+L` are no longer taken over (`Alt+Shift+D` = Download, `Alt+Shift+L` = Load, `Ctrl/Cmd+S` = Apply); closing a dialog any way re-enables the header buttons; new **Control Panel Connection** field (allowed Control Panel addresses)
- **Data Sources (unreleased feature) rebuilt:** one source at a time (Tour only / Google Sheets / CSV file), normal Google sharing links accepted, forgiving CSV (any separator, column titles), rows linked to tour elements by Title / Tag / Subtitle / id with `parentId` choosing the panorama, filled cells replace the result's title / description / image / tags, rows whose element is missing jump to their parent panorama, rows that lead nowhere are hidden, a **Test this source** button with a plain-language report, everything off by default; Apply Settings no longer switches the source off when CSV is selected
- **Clicking outside:** new setting `closeOnOutsideClick { mobile, desktop }` (default on = earlier behaviour) with toggles in the Control Panel General tab; off keeps the search open until it is closed with the button, Escape or a chosen result
- **Search field:** a very long text no longer breaks the layout (`box-sizing`, ellipsis)
- **Data Sources test report:** summary tiles that filter, searchable paged table, CSV download (tested with 6,000 rows); matching large sheets is about 90 times faster
- **Control Panel sync:** all 248 Control Panel fields checked end to end; fixed `minSearchChars` being overwritten by a stale `minSearchLength`, misplaced animation defaults, and the cache time default
- **Thumbnails (work in progress, branch `thumbnails`, phases T1 / T1b / L1 / H1):** results show the tour's own pictures (the tour exposes them as `thumbnailUrl`, which earlier versions never read), hotspots / objects / webframes borrow the picture of their panorama / 3D model; the small type icon on the picture is off by default (`typeBadge`: `none` / `all` / `borrowed`; icons only = thumbnails off); look options: picture shape (square, circle, 4:3, 16:9, 2:1) and fit, size per element type, badge look and colors, a different look on phones, generated placeholder tiles in a brand color, optional hover zoom of the picture (mouse rest on desktop, touch and hold on phones; off by default); all of it in the Control Panel (Display > Thumbnail Configuration)
- **General tab (G1-G3):** five sections with Restore Defaults; placement picker (top / middle / bottom x left / center / right) and a phone layout that cannot leave the screen; one breakpoint and an option to follow the tour's own phone version (script_mobile.js); Escape and Ctrl / Cmd + K on / off, open when the tour starts; typing delay, results limit, match tolerance, field priorities; editable visitor texts; invalid values are explained and not applied; the hidden Mobile Visibility Behavior and Element Triggering sections and four dead Advanced-tab fields are gone
- **New kinds of result, stage 1 (2026-10-11):** **Audio** (off by default, Content > What Is Searched): one result per audio file of the tour, a click plays it or pauses it while it plays; **Pick From the Open Tour** in Content > Containers lists the containers of the open tour (each name once, with how many share it and whether it is hidden at the start) and adds the ticked ones as rows; the Advanced scan and the Data Sources test now work before the first press of the tour's search button (the plugin listens from page load and starts the search without opening it when asked); the scan reports audio as read by the search. Not built yet: photos inside albums, hotspots on maps, text boxes, buttons, menu entries
- **Advanced tab, scan (2026-10-11):** new section "What the Search Sees in Your Tour" with a "Scan the Open Tour" button: the plugin counts the objects of the open tour by kind (15 kinds: panoramas, videos, albums, maps, 3D models, overlays, 3D objects, containers, album photos, map hotspots, audio, text boxes, buttons, menu entries) and the Control Panel shows how many exist, how many have a name, how many are in the search and what that means (read by the search / switched off in Content / left out by Content or Filtering / only typed containers / not searchable yet); read-only, uses the same channel as the Data Sources test; new plugin API `getTourInventory()`. In the test tour it shows what the search cannot find yet (5 photos, 1 map hotspot, 30 containers, 2 audios, 9 text boxes, 14 buttons, 9 menu entries)
- **Data Sources tab (2026-10-10):** three sections (Source, Sheet Columns, Remember the Sheet) in the DESIGN way, Restore Defaults for Source and Remember the Sheet, title "Data Sources Settings"; a notice appears while a source is on and Display hides what a sheet fills in (pictures, tags, subtitles) and the column table names the switch (the sheet picture was invisible by default because Display > Pictures is off); a link, a path or minutes that cannot be used are explained and no longer saved or sent to the tour; the Test report now says when a row finds nothing, or would not be shown, because Content or Filtering hide its element (it said "not found" for an element that exists); Filtering hints and the Master document say that filters use the tour's names and tags, not the sheet's; no console noise; matching, caching and reports otherwise unchanged
- **Filtering tab (2026-10-10):** three sections (Names, Tags, Panoramas by Number) with Restore Defaults instead of six cards and a warning banner; fixes: the element type boxes always showed as checked and the Apply / Download routine wrote all 15 types into both lists (a blacklist left 1 result of 71, a loaded type filter was overwritten), typed lists reached an open tour as text and filtered nothing, regular expressions lost their brackets and parentheses (`^Room-[12]$` found nothing), Reset buttons did not reach the tour; Element Type Filtering left the page (Content has the same switches; old files are translated), Element Label Filtering is merged into Names; Show Only names compare "Contains" by default, accents are ignored, lists may be given as text, panorama numbers are shown from 1, "Filters on" line and empty-list notice; the dead `filter.typeFilter` code is gone; `filtering-tab.js` 1,392 -> about 350 lines; new test suite `filtering` (written, not yet run)
- **Content tab (2026-10-10):** three sections (What Is Searched, Unnamed Items, Containers) with Restore Defaults; one table of the 16 kinds of element with a plain sentence each, Include All / Include None and the missing **Other Elements** switch (`includeElements`); the three unnamed-item switches now work for every kind of element, panoramas included (an element without a title is classified by its subtitle first, then its tags, then nothing: `includeContent.unlabeledWithSubtitles` / `unlabeledWithTags` / `completelyBlank`), and the old Skip Empty Labels is read as all three off (the plugin checked it for overlays only, with the label passed in already replaced by a fallback name); **defaults:** the built-in block no longer says `skipEmptyLabels: true` (it hid every unnamed overlay while unnamed panoramas stayed listed), the three switches are on, so unnamed elements are found, overlays included; Shortest Name Shown (`minLabelLength`) in characters; Containers explained (a 3DVista container dropped on the tour canvas), a list of rows like Tag Names with a phone name (the same container can be named differently in the desktop and the phone version of a tour) and an optional name for visitors (`containerSearch.containers`), one switch (`includeContainers`; the container search follows it); Photo Album, Map and Image come last in the table; the twelve dead label selects, `searchableProperties` and the stray `containerNames` are gone (old files are cleaned when read); Display's Use the Subtitle switch no longer shares the id `unlabeledWithSubtitles` with Content (clicking one label could flip the other); new test suite `content`
- **Display tab, round 2 (2026-10-10):** the icon picker has five kinds (Font Awesome, Bootstrap Icons, Ionicons, Emoji, Picture Address), a Current Icon row, a working "Back to the Standard Icon", Clear and Remove Picture, and aligned controls; **icon libraries in the tour:** each library loads only when a custom icon needs it, from `search-pro-v4/icons/` first, then from the CDN (integrity hash), and the built-in icon shows when both fail (earlier versions drew empty boxes when the CDN failed); Font Awesome in the tour is now 6.7.2 (the picker's icons exist there); the "Use Font Awesome" switch and its warning are gone (the plugin loads what an icon needs); the nothing-found icon takes any of the three icon fonts; the emoji list is Unicode Emoji 17 with real search, groups and a switch for the newest emojis (the old search returned every emoji); the Element Types table keeps all columns visible and greys the ones whose switch is off; table header tooltips are no longer cut off; new **Subtitle Instead of Name** switch (`display.onlySubtitles`); the three unused `display.showParent*` flags and the dead color-preview message handler are removed, `useAsLabel.elementType` defaults to off everywhere; Advanced tab: **one** search section (Search Tuning) with the former Search Settings fields in it; test runner prints a plain RESULT line
- **Display tab (P1 + P2):** five sections (What Results Show, Pictures, Icons, Element Types, Unnamed Items) instead of one 16,000 px page, a master switch each for pictures and icons, Restore Defaults in every section; one Element Types table (name, picture, size, placeholder file, icon per type) with one shared icon picker (Font Awesome, Emoji, Picture Address; search also finds other names such as "house" for the home icon); the settings that did nothing now work: `useAsLabel.parentLabel` / `parentWithType` (an unnamed hotspot can show "Hotspot in Room 1"), the picture side (`thumbnailSettings.alignment`); new `display.rowSpacing` (compact / normal / roomy) and `display.descriptionLines` (1-5); 3D object results name the 3D model as their parent; the Control Panel live preview reaches fields outside a form group; the icon list only holds icons the bundled Font Awesome Free 6.7.2 can draw (251 names that showed blank tiles are gone, all other Free icons added); `display-tab.js` 3,493 -> about 560 lines; defaults keep the earlier look
- **Group headers and count badge (P3c):** separate space above and below the group title, a full header border (each side), header background strength, the group count as a badge (background, strength, radius, space inside, weight, case, border); an error message under a number field disappears when the value is corrected; the General section "How Searching Works" moved to the Advanced tab as "Search Tuning" (same settings)
- **Appearance options (P3b):** no "+N" chip when only one tag may show; other names for tags (or hidden tags) without changing the tour, found by either name; group headers: space, corners, title weight / case / spacing, lines above and below, centered alignment; the scrollbar color works in current browsers (it was overridden by `scrollbar-color`) and has a size; the nothing-found message has its own icon (default, none, Font Awesome or emoji) and size
- **Appearance options (P3a):** borders for the search field and the results list (width 0-10, style, color, each side), a line between result rows, colors for the clear icon on hover, scrollbar and the nothing-found message, tag strength and background strength, most tags shown (+N chip), Space Inside as four fields, and the word before the tags (empty = none) in General > Visitor Texts; every default keeps the earlier look
- **Appearance tab (P1 + P2):** four sections that follow what the visitor sees (Search Field, Results List, Group Headers, Tags and Highlight), each with subsections and a Restore Defaults button; the focus ring replaces the three "text while active" fields (old saved values still work); font lists with Default and the tour's own fonts; clearer labels; one shared icon color; typography for the results list (font and five sizes) and a focus ring (both off / unchanged by default); every tag is its own chip and the tag fields say when tags are hidden; hex boxes beside the color pickers; sizes saved with their unit; invalid values explained and not applied; the unused `tagHover` color is gone; default placeholder and group-count colors changed to `#5f6f86` and placeholder strength to 1 (tours with saved values keep them)
