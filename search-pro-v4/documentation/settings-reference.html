How to Read This Page

Every setting, in eight groups, in the order of the Control Panel's tabs.

Each entry is one setting, written the way the Control Panel shows it. You do not need this page to use the Control Panel: every setting also has a help icon there. Use it to look a setting up, to see its default, or to find which tab holds it.

Part of an entry What it tells you
Name and kind The name is the one in the Control Panel. The kind says what you set: a switch, a number, a choice, a color, a text or a list.
Default The value you get after Restore Defaults or Reset, and in a fresh settings file.
Choices, Range, Length What the setting accepts. A number outside its range is not accepted.
Appears when, Needs A setting that only matters while another one has a value. The Control Panel hides it or dims it until then.
Desktop and Phone Some settings have one value for each. They are one entry with both values.
For each kind of result Panoramas, videos, hotspots and the other kinds each have their own value. The entry names the setting once, and the table of defaults under it lists every kind.
Find a setting by typing a word in the box above: tag, phone, border, delay. Press / anywhere on this page to jump to the box. The settings file holds more than 400 values in all.

General

Choose how the search opens and closes, how it finds results, and where it sits on computers and phones

Opening and Closing

Choose when the search opens and closes, for desktop and for phones, and what happens when a result sits in a window your tour keeps hidden.

Close After Choosing a Result

Switch for Desktop and Phone

Close the search as soon as a visitor picks a result. With Keep the Search Bar Visible on, only the results close.

Default
Desktop: Off · Phone: Off

Close When Clicking or Tapping Outside

Switch for Desktop and Phone

On: clicking or tapping anywhere else closes the search. Off: it stays open until the visitor closes it. With Keep the Search Bar Visible on, only the results close.

Default
Desktop: On · Phone: On

Open When the Tour Starts

Switch for Desktop and Phone

Open the search by itself as soon as the tour has started. If the tour waits on a start screen (3DVista Initialization: On Click or When Video Finished), it opens after the visitor starts the tour. Most tours leave this off.

Default
Desktop: Off · Phone: Off

Keep the Search Bar Visible

Switch for Desktop and Phone

On: the search bar stays on screen. Clicking or tapping outside, pressing Escape and choosing a result then hide only the results and empty the field. Off: they close the whole search bar. With Open When the Tour Starts on, the bar is there from the start. The button of your tour still opens and closes it.

Default
Desktop: Off · Phone: Off

Close With the Escape Key

Switch

On: one press of Escape clears the typed text and closes the search. Off: the search ignores Escape, so the tour can use it for its own windows and full screen. With Keep the Search Bar Visible on, Escape clears the text and the bar stays, and the tour keeps Escape while there is no text.

Default
On

Open With Ctrl or Cmd + K

Switch

Lets visitors open the search from the keyboard with Ctrl + K (Windows) or Cmd + K (Mac).

Default
On

Open Hidden Windows and Containers

Switch

Some results live in a window or container your tour keeps hidden, such as the floor plan, a photo album or a flat video. On: choosing such a result shows that window first, the way the tour's own button does. Off: the result is still selected, but the window stays hidden.

Default
On
