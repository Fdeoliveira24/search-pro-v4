What the Search Asks Other Websites For

The search runs in the visitor's browser and sends nothing to us. These are the only requests it can make to other websites, and each one has a condition.

Request When it happens Goes to
A backup copy of Fuse.js Only when fuse.js/dist/fuse.min.js cannot be loaded from your server cdn.jsdelivr.net
A backup copy of an icon font Only when a custom icon needs an icon font and its copy in the icons/ folder cannot be loaded, or when an old settings file still has the older Font Awesome switch on cdnjs.cloudflare.com or cdn.jsdelivr.net
Your Google Sheet Only when you choose Google Sheets in the Data Sources tab docs.google.com
Pictures and pages you add Only the web addresses you type yourself, for example a picture address The address you typed

The Control Panel and these pages load their own fonts and icons from their own folders.

Each backup copy is checked against a fixed fingerprint before it is used. If your visitors' network blocks these websites, upload the whole icons/ folder and fuse.js/dist/fuse.min.js and the search does not need them.
