Installation Guide

How to put Search Pro V4 in a 3DVista tour and make it yours.

What You Need

Four things, all of them ordinary tools.

  • Your 3DVista tour, published from the 3DVista desktop program (the folder that holds index.html)
  • A code editor to open index.html, such as Notepad, VS Code or Sublime Text (TextEdit works when it is set to plain text)
  • The search-pro-v4 folder from the zip file you received
  • A way to put files on your website: an FTP program or the file manager of your hosting

Put the Folder in Your Tour

The search lives in one folder. It must be at the same level as your tour files, in the same folder as your tour's index.html.

  1. Unzip the fileUnzip the file you received. Inside is the folder search-pro-v4/ with every part of the plugin.
  2. Keep a spare copyCopy the folder to a safe place before you change anything. If something goes wrong you can start again from it.
  3. Put it in your tour folderPut the search-pro-v4/ folder in your tour folder, at the same level as the index.html file: both sit side by side in the same folder.
Do not rename the folder. The search, the Control Panel and its Live Preview all look for the exact name search-pro-v4.

What Your Tour Folder Looks Like

  • your-tour/
    • index.htmlThe page 3DVista publishes. You add two lines to it.
    • script.js, lib/, media/ …The files 3DVista publishes. Never edit these.
    • search-pro-v4/The search. Put it here.
      • search-v4.jsThe search engine
      • css/Holds search-v4.css, the look of the search
      • config/Your settings file goes here (search-pro-config.js)
      • assets/The default pictures of the results
      • fuse.js/The word-matching library (dist/fuse.min.js)
      • icons/Icon fonts for custom result icons
      • business-data/Your CSV file, if you use one
      • extras/Button.js, the code for the 3DVista button
      • dashboard/The Control Panel

Add the Search Button

The search opens when a visitor presses a button. You make that button once, in 3DVista.

  1. Copy the button codeOpen search-pro-v4/extras/Button.js in your editor and copy everything in it, or use the Copy button below. 
    try {
    var searchContainer = document.getElementById('searchContainer');
    if (searchContainer) {
        if (!window.searchListInitiinitialized) {
            window.tourSearchFunctions.initializeSearch(this);
        }
        window.tourSearchFunctions.toggleSearch(searchContainer.style.display !== 'block');
    }
} catch (error) {
    console.error('Button action error - Check if initialization is complete:', error);
}
  2. Add a buttonIn 3DVista open your tour, go to the Skin tab and add an Icon Button. Choose an icon and place it where you want it.
  3. Give it its actionIn the Actions panel choose Execute JavaScript (JS), paste the code and click Done. Do not change the code.
  4. Preview and publishClick Preview to save, then Publish (Web/Mobile) to write your tour files.
Keep the code exactly as it is. The search looks for the names inside it.

Add Two Lines to index.html

Two lines tell the tour to load the search. The order of the lines matters.

  1. Open the tour index.html fileOpen the index.html file of your tour in a code editor.
  2. Find the viewer lineLook for the line <div id="viewer" class="fill-viewport"></div>, near the end of the file.
  3. Paste the two linesPaste the two lines below right after it, and before </body>. The search engine comes first and the settings file second. This is the order we tested and recommend. 
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  4. Save the fileSave index.html and upload it with your tour.

The End of Your index.html Then Looks Like This

<div id="viewer" class="fill-viewport"></div>
<script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
</body>
No settings file yet? Add only the first line for now. Add the second line when you have downloaded your settings file (see Save and Publish Your Settings).
Publishing again from 3DVista writes a new index.html. After every publish, add the two lines again.
If your tour has a loading screen, leave its block where it is: only add the two lines after the viewer line.
Do not replace the whole page. Only add the two lines. Never edit the other files 3DVista publishes.

Upload to Your Server

Put the tour and the search folder on your website. Not every file in the folder is needed there.

What to Upload

File or folder What it is Needed?
search-v4.js The search engine Required
css/search-v4.css The look of the search Required
fuse.js/dist/fuse.min.js The word-matching library. Only this one file of the folder is needed. Required
config/search-pro-config.js Your settings file, the one you download from the Control Panel Required
assets/ The default pictures of the results (20 files) Required when pictures are on
icons/ Icon fonts. Without them a tour asks another website for an icon font it needs. Recommended
business-data/ Your CSV file, only when Data Sources reads a CSV file If you use it
dashboard/ The Control Panel, with its fonts/, preview/ (the Live Preview), css/, js/, tabs/ and fontawesome/ folders. Upload all of it, or none. If you use it
extras/ The button code. Keep it on your computer. Not needed
The Control Panel needs the engine files too. Its Live Preview runs the real search, so if you upload dashboard/ also upload everything marked Required and Recommended.
File permissions: 644 for files and 755 for folders is usual. The server must be allowed to read every file.

Open the Control Panel

The Control Panel is where you change every setting and see the result at once.

  1. Check the uploadOn the server, the folder search-pro-v4/ must be at the same level as your tour files, in the same folder as your tour's index.html, with its dashboard/ folder inside.
  2. Open the addressIn your browser open https://your-domain.com/your-tour/search-pro-v4/dashboard/control-panel-v4.html (use your own domain and tour folder). Open it through the web address. Double-clicking the file on your computer does not work.
  3. Keep two tabs openKeep your tour in one browser tab and the Control Panel in another, in the same browser and at the same web address. A change then shows in the open tour at once, before you save anything.
A 404 error almost always means a typo in the address or the folder in the wrong place.

What You See

The sidebar lists the tabs: General, Appearance, Display, Content, Filtering, Data Sources, Animations, Advanced and Knowledge. Under the open tab it lists the cards of that tab.

Search settings (top bar, or press Ctrl or Cmd + K) finds a setting by a word and jumps to it.

Live Preview (the Preview button) shows the real search on a sample tour next to your settings, as it looks on a computer or a phone.

The page remembers where you were. When you reload the Control Panel it opens on the same tab and card.

Button What it does Who sees it
Apply Settings Keeps your settings in this browser. A tour you open here later uses them. Only you
Download Saves your settings as the file search-pro-config.js. Nobody yet
Load Reads a settings file you saved earlier back into the Control Panel. Use a file you downloaded from this Control Panel. Only you
Reset Puts every setting back to its default in this browser. The file on your server stays as it is. Only you

Visitors only see your settings after you download the file and upload it to your server. Closing the Control Panel does not lose your changes: when you open it again, it asks whether to bring them back. The exceptions are a reset and clearing your browser's data or cache, which remove them.

Every setting has its own entry in the Settings Reference, with what it does, its choices and its default.

Save and Publish Your Settings

Make your settings permanent and visible to every visitor.

Download and Upload

  1. Download the file from the DashboardOpen the Control Panel (the page in the dashboard/ folder) and press Download in its top bar. Your browser saves search-pro-config.js.
  2. Upload itWith your FTP program or the file manager of your hosting, put it in search-pro-v4/config/ and replace the old one.
  3. Reload without the cacheOpen your tour and press Cmd + Shift + R on a Mac or Ctrl + F5 on Windows. A browser keeps old files for a while and would show the old settings.
Do not edit the search-pro-config.js settings file by hand and do not delete lines. Change settings in the Control Panel and download the file again.

Keep Editing Later

  1. Load your fileOpen the Control Panel and press Load. Choose the search-pro-config.js you saved. Every tab then shows your settings again.
  2. Change and download againChange what you want, press Download and upload the new file.

Data Sources: Google Sheet or CSV

Optional. Give results their own names, descriptions, pictures and tags from a table you keep. The tour itself is never changed.

Prepare the Table

Row 1 holds the column titles: id, tag, name, description, imageUrl, tags, elementType, parentId.

Each following row describes one item of the tour. The id is the item's title in 3DVista, written exactly (capital letters do not matter). An empty cell keeps the tour's own value.

The Data Sources tab has a Download an example CSV button.

Connect It

  1. Choose the sourceOpen the Data Sources tab and choose Google Sheets or CSV file. Only one is active at a time.
  2. Google SheetShare the sheet as Anyone with the link: Viewer, paste the link into the Control Panel.
  3. CSV filePut your file in search-pro-v4/business-data/ and write its path in the Control Panel. Upload the CSV file to your server too: it is a second file next to your settings file.
  4. Press Test this sourceThe test says how many rows were read, which rows found their place in the tour and which did not, and why.
  5. Download and upload your settingsThe link or path is part of the settings file, so download it again and upload it as above.
Visitors find an item by the name, description and tags from your table, and still by the tour's own name. If the table cannot be read, visitors get the normal search with the tour's own names.
Keep a Copy (Data Sources tab) lets a visitor's browser keep a Google Sheet for a number of minutes, so changes in the sheet appear after that time. It is not used for CSV files.

Pictures in the Results

Optional but recommended. Each kind of result can show a picture of your tour or a default picture.

Where to Switch Them On

Open the Display tab and turn on Show Pictures in Results. Under Element Types choose, for each kind, whether its results show a picture, an icon or both, and the size of the picture.

The Placeholder File of a kind is the picture shown when an item has none of its own.

Supported: .jpg, .jpeg, .png, .gif, .webp, .svg. The 20 pictures that come with the plugin are 1920 × 1080 pixels (16:9). Use the same shape for yours.

  • Put every picture in search-pro-v4/assets/
  • The file name must match exactly the name in the Display tab
  • Capital letters matter in the file name, because file names are case sensitive: hotspot-default.jpg is not Hotspot-Default.jpg

If a Picture Does Not Show

Check the file name and its ending (.jpeg is not .jpg). Open the picture directly: https://your-domain.com/your-tour/search-pro-v4/assets/yourfile.jpg.

An old picture still showing: reload without the cache, or clear the cache of your hosting or CDN for that file.

Hide or Show Only Some Results

The Filtering tab decides which results visitors never see.

  • By name: choose Hide These or Show Only These and list the names. A name matches when it contains the words you list.
  • By tag: the same, with the tags you gave in 3DVista. With Show Only, an item without tags is left out, panoramas and containers too.
  • Panoramas by Number: the same, with numbers, one per line. A number is the place of a panorama, video or 3D model in the Main Playlist of your tour, counted from 1. Containers are not affected.

Filtering compares the names and tags of the tour, not the ones from a Data Sources table.

  • Not finding a result you expect? Check which kinds are switched on in Content and what Filtering hides. Scan the Open Tour in the Advanced tab shows what the search can see in your tour.
  • Too much information showing? Review the other settings too, such as the kinds switched on in Content, to make filtering more accurate.

Keep the Search Bar on Screen

Optional. Show the Search Bar from the start and keep it there, on computers, on phones or on both.

The Search Bar is the box visitors type in. The Search Results are the list under it. By default the whole search, bar and results, goes away when a visitor chooses a result, clicks or taps outside it, or presses Escape. With the settings below the Search Bar is there when the tour starts and stays on screen. Only the Search Results go away.

  1. Open the General tabIn the Control Panel open General and find the section Opening and Closing.
  2. Show the Search Bar from the startSwitch on Open When the Tour Starts for Desktop, Phone or both.
  3. Keep it on screenLeave the three Hide the Search Results settings on, and switch off the three Also Hide the Search Bar settings (After Choosing a Result, When Clicking or Tapping Outside, With the Escape Key) for the same device types.
  4. Download and upload your settingsSee Save and Publish Your Settings.

What Visitors See

  • A click or tap outside hides only the Search Results and empties the field. The Search Bar stays.
  • Escape clears the text and hides the Search Results. While the field is empty, Escape is left to your tour.
  • Choosing a result hides the Search Results and clears the text. The Search Bar stays.
  • Typing again shows the Search Results again. Ctrl or Cmd + K puts the cursor in the field.
  • The search button of your tour, if you added one, still opens and closes the whole search.
A Search Bar that stays does not need the 3DVista button. Add the button only if visitors should be able to hide the Search Bar.
On a phone the Search Bar takes room from the tour. Check how it looks on your own phone before you publish.

Coming From Version 3

Your button stays, your settings come with you. The folder and the two lines in index.html change.

Replace the old search, do not add a second one. A tour must load only one search, so the two Version 3 lines go away when the Version 4 lines go in.
  1. Keep your settings fileCopy search-pro-v3/config/search-pro-config.js to your computer. You will load it into the new Control Panel.
  2. Put the new folder next to the old onePlace search-pro-v4/ at the same level as your tour files, in the same folder as index.html (see Put the Folder in Your Tour). Leave search-pro-v3/ where it is for now.
  3. Switch the two lines in index.htmlTake out the two Version 3 lines and paste the two Version 4 lines in their place, in the same order. 
    <script src="search-pro-v3/search-v3.js"></script>
<script src="search-pro-v3/config/search-pro-config.js"></script>
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  4. Keep your buttonThe button code is the same in both versions, so the button in 3DVista needs no change. Do not add it again.
  5. Bring your settings overOpen the new Control Panel (search-pro-v4/dashboard/control-panel-v4.html), press Load and choose your Version 3 file. Settings that exist in both versions come across. Look through the tabs, then press Download: the new file also holds the settings Version 4 added.
  6. Upload and reloadUpload the search-pro-v4/ files (see Upload to Your Server), the new settings file in search-pro-v4/config/ and your changed index.html. Reload your tour without the cache.
  7. Remove the old folderWhen the tour works as you expect, remove search-pro-v3/ from your server or local directory.

Good to Know

  • Version 4 can also read a Version 3 settings file as it is, so nothing breaks if the old file is still in place when you switch. Loading it and downloading it again is how you get a Version 4 file.
  • The address of the Control Panel changes: it is now search-pro-v4/dashboard/control-panel-v4.html.

Update to a New Version

Your settings file stays. Only the plugin files change.

  1. Keep your settings fileMake a copy of search-pro-v4/config/search-pro-config.js on your computer.
  2. Upload the new filesUpload the files of the new search-pro-v4 folder over the old ones, and replace the files that exist. Do not delete the config/ folder: your settings file lives there.
  3. Reload without the cacheOpen your tour and press Cmd + Shift + R or Ctrl + F5, so the browser does not keep the old engine.
  4. Look through the Control PanelOpen the Control Panel, press Load with your settings file, look through the tabs and press Download again, so the file includes the settings the new version added. Upload that file to config/.
  • Your two lines in index.html and the button in 3DVista stay the same. Nothing needs to change there.

Help and Troubleshooting

Common problems, quick fixes and how to get help.

Common Problems

Problem What to check
The settings do not show in the tour Apply Settings only changes your own browser. Download the file, upload it to search-pro-v4/config/ and reload without the cache. In index.html check that the engine line comes first and the settings line second.
The search button does nothing Check that the button has the JavaScript action and that search-pro-v4/search-v4.js loads. Open the browser console (F12) and look for a red message.
A file is not loading Check the spelling and place of the file. In the browser console look for 404 (not found) or 403 (not allowed) messages.
The Search Bar disappears when visitors click on the tour That is the default: a click outside hides the Search Results and the Search Bar. To keep the Search Bar on screen, switch off Also Hide the Search Bar When Clicking or Tapping Outside in General (see Keep the Search Bar on Screen).
A 403 (not allowed) message Check the file permissions: 644 for files and 755 for folders is usual. The server must be allowed to read every file.
Choosing a result does not show the floor plan, album or video Your tour keeps them in a window that is hidden. Turn on Open Hidden Windows and Containers in General.
My changes do not reach the open tour Open the Control Panel and the tour in the same browser and at the same web address. If the Control Panel is on another address, add it in Advanced under Control Panel Connection. The same goes for a tour shown inside another web page: that page is only listened to when its address is listed there.
My settings are gone after closing the Control Panel When you open it again it asks whether to bring them back. After a reset, or after clearing your browser's data or cache, they cannot be brought back: press Load and choose the file you downloaded. Only the downloaded file is kept for good.

The 5-Step 60-Second Check

  1. Can you open the Control Panel address?
  2. Does a change in the Control Panel show in the open tour without a reload?
  3. Did you download the settings file and upload it to search-pro-v4/config/?
  4. Did you reload the tour without the cache?
  5. Does the tour show your settings now?

Secure Your Control Panel

Anyone who finds the address of your Control Panel can open it. It cannot change your live tour without the settings file being uploaded, but protect it anyway once your settings are final.

  1. Option 1: delete it (recommended)Remove the search-pro-v4/dashboard/ folder from your server once your final settings file is uploaded. The search keeps working with only search-pro-config.js. You can upload the folder again whenever you want to make changes.
  2. Option 2: password protect itUse the password protection of your hosting (for Apache, a .htaccess file) on the search-pro-v4/dashboard/ folder.

Clean Uninstall

  1. Take the button outRemove the JavaScript action from the 3DVista button (or delete the button) and publish again.
  2. Take the two lines outRemove these two lines from index.html: 
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  3. Remove the folderRemove the search-pro-v4/ folder from your server.
