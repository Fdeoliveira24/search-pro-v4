What You Need

Four things, all of them ordinary tools.

  • Your 3DVista tour, published from the 3DVista desktop program (the folder that holds index.html)
  • A code editor to open index.html, such as Notepad, VS Code or Sublime Text (TextEdit works when it is set to plain text)
  • The search-pro-v4 folder from the zip file you received
  • A way to put files on your website: an FTP program or the file manager of your hosting

Put the Folder in Your Tour

The search lives in one folder. It must sit beside your tour's index.html.

Place the Folder

Unzip the file

Unzip the file you received. Inside is the folder search-pro-v4/ with every part of the plugin.

Keep a spare copy

Copy the folder to a safe place before you change anything. If something goes wrong you can start again from it.

Put it in your tour folder

Put the search-pro-v4/ folder in your tour folder, at the same level as the index.html file: both sit side by side in the same folder.

Do not rename the folder. The search, the Control Panel and its Live Preview all look for the exact name search-pro-v4.

Add the Search Button in 3DVista

The search opens when a visitor presses a button. You make that button once, in 3DVista.

Make the Button

Copy the button code

Open search-pro-v4/extras/Button.js in your editor and copy everything in it. The same code is on the Knowledge page of the Control Panel, with a Copy button.

Add a button

In 3DVista open your tour, go to the Skin tab and add an Icon Button. Choose an icon and place it where you want it.

Give it its action

In the Actions panel choose Execute JavaScript (JS), paste the code and click Done. Do not change the code.

Preview and publish

Click Preview to save, then Publish (Web/Mobile) to write your tour files.

Keep the code exactly as it is. The search looks for the names inside it.

How the Button Works

  • The first press prepares the search. In a large tour this takes a moment.
  • Each press after that opens or closes the search.

Add Two Lines to index.html

Two lines tell the tour to load the search. The order of the lines matters.

Where the Lines Go

Open index.html

Open the index.html file of your tour in a code editor.

Find the viewer line

Look for this line, near the end of the file: <div id="viewer" class="fill-viewport"></div>

Paste the two lines

Paste the two lines below right after it, and before </body>. The search engine comes first and the settings file second. This is the order we tested and recommend.

Save the file

Save index.html and upload it with your tour.

<script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>

The end of your index.html then looks like this:

<div id="viewer" class="fill-viewport"></div>
<script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
</body>
No settings file yet? Add only the first line for now. Add the second line when you have downloaded your settings file (see Save and Publish Your Settings).
Publishing again from 3DVista writes a new index.html. After every publish, add the two lines again. If your tour has a loading screen, leave its block where it is: only add the two lines after the viewer line.
Do not replace the whole page. Only add the two lines. Never edit the other files 3DVista publishes.

Open the Control Panel

The Control Panel is where you change every setting and see the result at once.

Open It

Check the upload

The folder search-pro-v4/ must sit beside your tour's index.html on the server, with its dashboard/ folder inside.

Open the address

In your browser open https://your-domain.com/your-tour/search-pro-v4/dashboard/control-panel-v4.html (use your own domain and tour folder). Open it through the web address. Double-clicking the file on your computer does not work.

Keep two tabs open

Keep your tour in one browser tab and the Control Panel in another, in the same browser and at the same web address. A change then shows in the open tour at once, before you save anything.

A 404 error almost always means a typo in the address or the folder in the wrong place.

What You See

  • The sidebar lists the tabs: General, Appearance, Display, Content, Filtering, Data Sources, Animations, Advanced and Knowledge. Under the open tab it lists the cards of that tab.
  • Search settings (top bar, or press Ctrl or Cmd + K) finds a setting by a word and jumps to it.
  • Live Preview (the Preview button) shows the real search on a sample tour next to your settings, as it looks on a computer or a phone.
  • The page remembers where you were. When you reload the Control Panel it opens on the same tab and card.
Button What it does Who sees it
Apply Settings Keeps your settings in this browser. A tour you open here later uses them. Only you
Download Saves your settings as the file search-pro-config.js. Nobody yet
Load Reads a settings file you saved earlier back into the Control Panel. Use a file you downloaded from this Control Panel. Only you
Reset Puts every setting back to its default in this browser. The file on your server stays as it is. Only you
Visitors only see your settings after you download the file and upload it to your tour. Closing the Control Panel does not lose your changes: when you open it again it asks whether to bring them back.

Save and Publish Your Settings

Make your settings permanent and visible to every visitor.

Download and Upload

Download the file

Press Download in the top bar. Your browser saves search-pro-config.js.

Upload it

With your FTP program or the file manager of your hosting, put it in search-pro-v4/config/ and replace the old one.

Reload without the cache

Open your tour and press Cmd + Shift + R on a Mac or Ctrl + F5 on Windows. A browser keeps old files for a while and would show the old settings.

Do not edit the settings file by hand and do not delete lines. Change settings in the Control Panel and download the file again.

Keep Editing Later

Load your file

Open the Control Panel and press Load. Choose the search-pro-config.js you saved. Every tab then shows your settings again.

Change and download again

Change what you want, press Download and upload the new file.

Data Sources: Google Sheet or CSV

Optional. Give results their own names, descriptions, pictures and tags from a table you keep. The tour itself is never changed.

Prepare the Table

  • Row 1 holds the column titles: id, tag, name, description, imageUrl, tags, elementType, parentId.
  • Each following row describes one item of the tour. The id is the item's title in 3DVista, written exactly (capital letters do not matter).
  • An empty cell keeps the tour's own value.
  • The Data Sources tab has a Download an example CSV button.

Connect It

Choose the source

Open the Data Sources tab and choose Google Sheets or CSV file. Only one is active at a time.

Google Sheet

Share the sheet as Anyone with the link: Viewer, paste the link into the Control Panel.

CSV file

Put your file in search-pro-v4/business-data/ and write its path in the Control Panel. Upload the CSV file to your server too: it is a second file next to your settings file.

Press Test this source

The test says how many rows were read, which rows found their place in the tour and which did not, and why.

Download and upload your settings

The link or path is part of the settings file, so download it again and upload it as above.

Visitors find an item by the name, description and tags from your table, and still by the tour's own name. If the table cannot be read, visitors get the normal search with the tour's own names.
Keep a Copy (Data Sources tab) lets a visitor's browser keep a Google Sheet for a number of minutes, so changes in the sheet appear after that time. It is not used for CSV files.

Pictures in the Results

Optional but recommended. Each kind of result can show a picture of your tour or a default picture.

Where to Switch Them On

  • Open the Display tab and turn on Show Pictures in Results.
  • Under Element Types choose, for each kind, whether its results show a picture, an icon or both, and the size of the picture.
  • The placeholder file of a kind is the picture shown when an item has none of its own.

File rules:
  • Put every picture in search-pro-v4/assets/
  • The file name must match exactly the name in the Display tab
  • Capital letters count: hotspot-default.jpg is not Hotspot-Default.jpg

If a Picture Does Not Show

  • Check the file name and its ending (.jpeg is not .jpg).
  • Open the picture directly: https://your-domain.com/your-tour/search-pro-v4/assets/yourfile.jpg
  • An old picture still showing: reload without the cache, or clear the cache of your hosting or CDN for that file.

Hide or Show Only Some Results

The Filtering tab decides which results visitors never see.

  • By name: choose Hide These or Show Only These and list the names. A name matches when it contains the words you list.
  • By tag: the same, with the tags you gave in 3DVista. With Show Only, an item without tags is left out, panoramas and containers too.
  • Filtering compares the names and tags of the tour, not the ones from a Data Sources table.
Not finding a result you expect? Check which kinds are switched on in Content and what Filtering hides. Scan the Open Tour in the Advanced tab shows what the search can see in your tour.

Update to a New Version

Your settings file stays. Only the plugin files change.

Keep your settings file

Make a copy of search-pro-v4/config/search-pro-config.js on your computer.

Upload the new files

Upload the files of the new search-pro-v4 folder over the old ones, and replace the files that exist. Do not delete the config/ folder: your settings file lives there.

Reload without the cache

Open your tour and press Cmd + Shift + R or Ctrl + F5, so the browser does not keep the old engine.

Look through the Control Panel

Open the Control Panel, press Load with your settings file, look through the tabs and press Download again, so the file includes the settings the new version added. Upload that file to config/.

Your two lines in index.html and the button in 3DVista stay the same. Nothing needs to change there.

Help and Troubleshooting

Common problems, quick fixes and how to get help.

Common Problems

Problem What to check
The settings do not show in the tour Apply Settings only changes your own browser. Download the file, upload it to search-pro-v4/config/ and reload without the cache. In index.html check that the engine line comes first and the settings line second.
The search button does nothing Check that the button has the JavaScript action and that search-pro-v4/search-v4.js loads. Open the browser console (F12) and look for a red message.
A file is not loading Check the spelling and place of the file. In the browser console look for 404 (not found) or 403 (not allowed) messages.
Choosing a result does not show the floor plan, album or video Your tour keeps them in a window that is hidden. Turn on Open Hidden Windows and Containers in General.
My changes do not reach the open tour Open the Control Panel and the tour in the same browser and at the same web address. If the Control Panel is on another address, add it in Advanced under Control Panel Connection. The same goes for a tour shown inside another web page: that page is only listened to when its address is listed there.
My settings are gone after closing the Control Panel When you open it again it asks whether to bring them back. Only the downloaded file is kept for good.

60-Second Check

  1. Can you open the Control Panel address?
  2. Does a change in the Control Panel show in the open tour without a reload?
  3. Did you download the settings file and upload it to search-pro-v4/config/?
  4. Did you reload the tour without the cache?
  5. Does the tour show your settings now?

Secure Your Control Panel

Anyone who finds the address of your Control Panel can open it. It cannot change your live tour without the settings file being uploaded, but protect it anyway once your settings are final.

Option 1: delete it (recommended)

Remove the search-pro-v4/dashboard/ folder from your server once your final settings file is uploaded. The search keeps working with only search-pro-config.js. You can upload the folder again whenever you want to make changes.

Option 2: password protect it

Use the password protection of your hosting (for Apache, a .htaccess file) on the search-pro-v4/dashboard/ folder.

Clean Uninstall

  1. Remove the JavaScript action from the 3DVista button (or delete the button) and publish again.
  2. Remove these two lines from index.html: 
    <script src="search-pro-v4/search-v4.js"></script>
<script src="search-pro-v4/config/search-pro-config.js"></script>
  3. Remove the search-pro-v4/ folder from your server.
